# Persona 3 Reload–Inspired Personal Website

A personal website inspired by the menu UI and visual style of **Persona 3 Reload**! The project explores game-inspired navigation, expressive typography, and animated transitions as a way to present a personal identity on the web. 

Built with React and Vite, it is being developed into an original personal site with its own content, layout, and features. This is an inspo'd website by Fruitymimi and this website serves as an initial source of inspiration; the final design and direction will evolve independently. The visual inspiration comes from *Persona 3 Reload*. This is an unofficial personal fan project and is not affiliated with or endorsed by ATLUS or SEGA.
